# 正解データ

`gold_*.csv` は、学会別抽出器の出力から範囲を決めて切り出し、元のプログラムページと1件ずつ照合した正解データです（MIRU・ANLP は開発用）。

## 範囲（完全なセッション単位）
- MIRU2026：オーラル 1A〜1F
- NLP2026：A1（口頭、ポスターの再掲を含む）、B1、P1

## 確認のしかた
元のプログラムページを開き、上の範囲のセッションを1件ずつ照らし合わせる。
- 「確認」列：合っていれば `ok`、タイトルや著者が違えば `fix`（正しい値に直す）
- 元ページにあるのに CSV に無い発表は、行を追加して「確認」列を `missing` にする
- 対象外（招待講演など）が混ざっていたら `exclude`

「確認」列が ok / fix / missing 以外の行が残っていると、評価スクリプトは下書きとして警告します。

# 未見大会（12月の評価用、TK-10・TK-37）

`unseen_conferences.csv` は評価用の5大会（`python -m confprog.locate --list` にそのまま渡せる形）、
`unseen_pages.csv` は各大会で保存したページと、ページ特定の正解です。大会の選び方は TK-10（Vault `調査・結果/未見大会_評価用_2026-11-09.md`）。

- 群A（開発で見たサイトと同じ作りの別の回）：IPSJ87、YANS2024
- 群B（初見の構造、本命）：FIT2025、HAI2025、SLUD（第16回対話システムシンポジウム）

## unseen_pages.csv の「役割」
- `正解`：発表一覧が載っているページ。ページ特定はこれを全部返せば正解（複数ページに分かれる大会は全部）
- `トップ`：学会リストに与える大会トップ
- `中継`：トップから正解までの途中にあるメニュー・案内ページ（発表一覧ではない）
- `参考`：正解と同じ発表の別の並べ方や一部の再掲。返しても誤りとは数えないかは評価方法（TK-44）で決める
- `旧年`：大会のサイトの中にあるが、別の年の発表が残っているページ（返したら誤り）

## 気づいたこと（正解作りで注意）
- HAI2025 の program.html は HTML コメントの中に旧年のポスター一覧（P-1〜P-74）が残っている。画面に出るのはコメントの外（口頭 G-1〜、ポスター P1-1〜・P2-1〜）だけ
- HAI2025 のメニューの「ショート発表」（short.htm）は2021年の回の申込一覧で、2025年の発表ではない
- FIT2025 は IPSJ 全国大会と同じ情報処理学会のサイトだが、一覧のページの作り（表とモーダル）は全国大会（div の並び）と違うので群Bのままにした
- YANS2024 の記事のサイドバーには最新回（2026）のプログラムへのリンクがある

## スナップショット
HTML 本体は `data/unseen/2026-11-14/raw/`（`fetch()` で取ったもの）と `rendered/`（`render()` の描画後）にあり、
ファイル名は `fetch.cache_path()` と同じ規則です（再配布可否が未確認なのでコミットしない）。`raw_sha1` は raw の先頭12桁。
12月に一度だけ回すときは、このフォルダを `data/raw`・`data/rendered` に置いて（またはキャッシュ先を向けて）通信せずに読む。
サイトが更新されても時点を揃えるためです。
