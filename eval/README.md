# 正解データ（作成中）

`gold_draft_*.csv` は、学会別抽出器の出力から**範囲を決めて切り出した下書き**です。まだ正解ではありません。

## 範囲（完全なセッション単位）
- MIRU2026：オーラル 1A〜1F
- NLP2026：A1（口頭、ポスターの再掲を含む）、B1、P1

## 確認のしかた
元のプログラムページを開き、上の範囲のセッションを1件ずつ照らし合わせる。
- 「確認」列：合っていれば `ok`、タイトルや著者が違えば `fix`（正しい値に直す）
- 元ページにあるのに CSV に無い発表は、行を追加して「確認」列を `missing` にする
- 対象外（招待講演など）が混ざっていたら `exclude`

全行の確認が終わったら `gold_*.csv` に名前を変えて、正解データとして使う。
